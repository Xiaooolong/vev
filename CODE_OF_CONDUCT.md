# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be respectful in issues, pull requests and discussions.

To report unacceptable behaviour, contact the maintainer privately through GitHub
([@Xiaooolong](https://github.com/Xiaooolong)). Reports are kept confidential.
